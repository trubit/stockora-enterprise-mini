# Financial Budgeting & Variance Analysis

## Overview
Allows corporate finance managers to allocate department, branch, and category-level expense budgets, tracking real-time variance and overrun alerts.

### Budget Execution
- Compares Allocated vs Spent vs Committed Capital.
- Triggers alert notifications when spending reaches threshold (e.g. $85\%$).
- Automatically flags status as `EXCEEDED` if actual spend surpasses $100\%$ allocation.
