# AI Customer Intelligence Assistant & Grounded Insights

## Overview
Powered by `CRMAIService` utilizing live database grounding and multi-provider LLM execution.

### Key Capabilities
1. **Grounded CRM Assistant**: Answers natural language inquiries regarding customer lifetime value, churn risk root causes, high-value segments, and optimal campaign strategies.
2. **Deterministic Context Grounding**: Context injected into prompts is strictly retrieved from verified active database entities, preventing LLM hallucinations.
