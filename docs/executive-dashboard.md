# Stockora Enterprise — Executive Dashboard

## Overview
The Executive Dashboard is designed as an interactive command center for C-Suite executives, business owners, and regional managers.

## Key Features
- **Flexible Time Period Filtering**: Today, Yesterday, 7 Days, 30 Days, 90 Days, This Month, Last Month, This Quarter, This Year, Custom Range.
- **Dynamic Comparisons**: Period-over-period, month-over-month, quarter-over-quarter, and year-over-year with automatic growth % indicators.
- **Responsive Architecture**: Multi-breakpoint layout optimized for desktop, tablet, and mobile viewing.
- **Instant CSV & Data Exporting**: Single-click streaming export of executive summaries.
